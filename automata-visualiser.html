MACHINE 02 / PDA

Does the structure hold?

The PDA checks nested acts, scenes and cue groups using a stack. Open a structure to push it; close it to match and pop the most recently opened element.

A

STRUCTURAL INPUT

Build the nesting.

Symbols: OPEN_ACT / CLOSE_ACT · OPEN_SCENE / CLOSE_SCENE · OPEN_GROUP / CLOSE_GROUP. The stack begins with the bottom marker $.

STACK RULE

A closing event must match the most recently opened structure. The sequence is accepted only when the stack returns to its bottom marker.
